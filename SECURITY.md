# Security Policy

## Reporting Security Issues

We take the security and integrity of **Orbis Tech Kids FM** and our community very seriously.

If you discover any security vulnerability, sensitive data exposure, or client-side risk, please report it responsibly:

- **Private Reporting:** Use GitHub's private vulnerability reporting feature on this repository.
- **Direct Contact:** Contact the project maintainer via WhatsApp at [https://wa.me/5574999140925](https://wa.me/5574999140925).

Please **do not** report security vulnerabilities via public GitHub issues.

## Guidelines

- This project is a frontend static web player hosted via GitHub Pages, streaming audio from an AzuraCast audio server (`https://radio.vml10.xyz`).
- Do not commit any personal API keys, passwords, authentication tokens, private server credentials or internal network IPs to this repository.
- All public weather and geolocation integrations must use open, zero-credential APIs (such as Open-Meteo).
